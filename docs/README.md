# Project Documentation

This directory keeps both the original planning documents and the current implementation summary.

The original May 20 planning docs describe the earlier "wishlist releases in calendar" prototype. The current product direction, captured in `current-status.md`, is **Steam Sale Calendar**: an account-free Steam sale/event/watched-game calendar that can also import a public wishlist.

## Index

- `current-status.md` — concise summary of the product and code that exists now.
- `product-design.md` — historical product/design plan generated during office-hours review.
- `engineering-plan.md` — historical engineering plan generated during implementation planning.
- `test-plan.md` — focused test plan generated from the engineering review.
- `assets.md` — runtime and design asset locations.
