Generated by /plan-eng-review on 2026-05-20

Repo: wishlist-in-calender

Updated on 2026-05-25 for the Steam Sale Calendar direction.

## Affected Pages/Routes

- `/` — Steam sale calendar editor with store region, event filters, deal count, game search/watch controls, wishlist import, preview, and generated feed URLs.
- `/api/public-preview` — returns account-free Steam deal/event/manual watched-game preview data from URL query settings.
- `/api/preview` — validates SteamID64/profile URL input, fetches public wishlist, and returns preview events/errors.
- `/api/search-games` — searches Steam games through Steam CLI.
- `/feed/{steamId64}.ics` — returns `text/calendar` feed for calendar apps.
- `/cal/{steamId64}` — extensionless webcal subscription route.

## Key Interactions to Verify

- Load `/` without entering a Steam account and see useful default calendar items.
- Change the Steam store country/region and confirm the generated subscription URL includes `cc`.
- Change the language and confirm the generated subscription URL includes matching `lang` and `uiLang`.
- Toggle deal/event/wishlist settings and confirm the generated URL query updates.
- Filter official Steam event types and confirm `eventTypes` updates.
- Change deal count and confirm `count` updates.
- Search for a Steam game, add it, and see it added to the selected list and calendar preview.
- Paste a Steam appID or Steam store app URL into the game search box and confirm it resolves to an addable game.
- Confirm adding a game animates the selected row and calendar event.
- Connect a public wishlist and confirm manual app IDs are ignored while wishlist mode is active.
- Enter a valid SteamID64 on `/` and see exact-dated wishlist release events.
- Enter a numeric or custom Steam profile/wishlist URL and see it normalize into the same feed.
- Enter malformed input and see a clear validation error without arbitrary URL fetch.
- Enter a private/hidden/unavailable wishlist and see fallback copy.
- Generate a feed URL from preview.
- Copy the HTTPS feed URL and confirm it includes settings, store region, and language.
- Open the feed URL and confirm `Content-Type: text/calendar; charset=utf-8`.
- Confirm feed contains `VCALENDAR`, stable `UID`, all-day release events, and major Steam events.
- Subscribe to deployed feed URL in Apple Calendar and confirm events appear.

## Edge Cases

- Steam CLI unavailable; wishlist fallback still works where supported and account-free preview degrades clearly.
- Steam CLI cache disabled with a `0` TTL.
- Multiple identical preview/search requests dedupe in-process.
- Browser language and Steam store country remain separate concepts.
- Unsupported profile URL rejected with clear message.
- Steam profile URLs with unsupported extra path segments are rejected with a clear message.
- Non-Steam URL rejected before fetch.
- Steam timeout returns clear error state.
- Steam returns HTML/403/bot-block response.
- Empty wishlist or no exact release dates.
- Wishlist contains TBD, Coming Soon, year-only, or month-only release strings.
- Wishlist exceeds item cap; preview remains usable.
- Partial app metadata failure; remaining valid apps still appear.
- iCalendar escaping for comma, semicolon, backslash, newline.
- Date range `DTEND` is exclusive.

## Critical Paths

- Account-free default settings → Steam CLI deals/events fetched → preview shown → `.ics` generated → OS calendar subscription works.
- Manual game search → app selected → query encoded with `apps` → preview/feed include watched game when discounted or unreleased.
- Public SteamID64 → wishlist fetched → exact release events mapped → preview shown → `.ics` generated → OS calendar subscription works.
- Invalid input → no external fetch → clear user-facing error.
- Steam unavailable → no silent failure → user sees retry/fallback message.
